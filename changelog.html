December 2024
v1.0.0

Initial Release

We're excited to launch FileUploadGPT! This initial release includes all the core functionality you need to upload large files to ChatGPT.

Features

  • Upload large files to ChatGPT beyond native size limits
  • Support for PDF, DOCX, TXT, MD, HTML file formats
  • Support for data files (CSV, JSON)
  • Support for code files (JS, PY, and more)
  • Intelligent chunking to preserve context
  • One-click upload interface
  • Progress indicator for large files
  • Configurable chunk size settings
  • Local file processing (privacy-first)
  • Works with ChatGPT Free and Plus

Technical

  • Built with Manifest V3 for Chrome
  • Compatible with Chrome, Edge, Brave, and other Chromium browsers
  • Minimal permissions requested
  • No external server dependencies
