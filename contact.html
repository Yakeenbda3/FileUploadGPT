Common Questions

These FAQs might help answer your question faster.

The extension isn't working — what should I do?

Try refreshing the ChatGPT page, then ensure you're on chat.openai.com (not another OpenAI page). Check that the extension is enabled in chrome://extensions. If issues persist, try disabling other ChatGPT extensions temporarily.

My file isn't uploading — how do I fix it?

Make sure your file is a supported format (PDF, DOCX, TXT, MD, HTML, CSV, JSON, or code files). Try refreshing the page and attempting the upload again. If the file is very large, it may take longer to process.

How do I report a bug?

Use the form above with "Bug Report" as the subject. Include your browser version, steps to reproduce the issue, and any error messages you saw. Screenshots are helpful too!
