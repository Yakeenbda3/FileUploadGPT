## Image Guidelines

### Brand Colors
- Primary Blue: #4F46E5
- Dark: #1F2937
- Light Background: #F9FAFB
- Success Green: #10B981

### Style Recommendations
1. **Screenshots**: Use a clean, modern browser chrome or no chrome
2. **Icons**: Flat design, consistent stroke width (1.5-2px)
3. **OG Images**: Include logo, article title, and visual element
4. **Backgrounds**: Use gradients from brand colors

### File Optimization
- Use PNG for screenshots and icons
- Use WebP for photos (with PNG fallback)
- Compress all images (TinyPNG, ImageOptim)
- Target file sizes:
  - Icons: < 10KB
  - Screenshots: < 100KB
  - OG Images: < 150KB

## Quick Start

To get the website looking complete quickly, prioritize these images:

1. ⭐ `logo.png` - Main branding
2. ⭐ `icon.png` - Extension icon
3. ⭐ `og-image.png` - Social sharing
4. ⭐ `hero-screenshot.png` - Homepage hero
5. ⭐ `chrome-web-store-badge.png` - CTA reinforcement

The website will function without images (placeholder gradients are in place), but these five will significantly improve the professional appearance and social sharing preview.
